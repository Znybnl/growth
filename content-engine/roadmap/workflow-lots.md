# Workflow éditorial par lots

Demande à Codex : « Prépare les quatre prochains articles SEO/GEO les plus pertinents pour Okado ». Codex actualise l'inventaire et, si possible, compare le sitemap ; il propose des opportunités sans inventer de données de recherche, compare aussi les sujets entre eux et choisit créer, enrichir ou abandonner. Pour actualiser : « Actualise [URL] », conserver l'URL et la date de publication, modifier la date de mise à jour uniquement en cas de révision substantielle.

Pour chaque sujet, créer un brief distinct dans `briefs/` selon `example.json` et un dossier de sources et d'affirmations avec titre, URL, date de publication si connue, date de consultation, preuve et incertitude. Tracer la décision, les articles proches, l'intention, le CTA et les points de vérification. Consigner individuellement BLOCKED, NEEDS_EDITS ou READY_FOR_HUMAN_REVIEW. Le statut READY signifie prêt à être relu et ne constitue jamais une autorisation de publication.

Le documentaliste consulte les sources primaires et vérifie les capacités produit ; le rédacteur utilise le registre du site ; l'auditeur vérifie faits, recoupements, liens et risques ; l'intégrateur lance les validations et génère une copie lisible : `node content-engine/scripts/reading-copy.mjs /blog/slug chemin.md`. Si une source manque pour un article, consigner son blocage et poursuivre les autres ; ne jamais inventer de preuve, ni inclure un article bloqué dans le registre publiable. Un échec commun de build ou de sécurité bloque le lot avant livraison. Conserver les brouillons non prêts hors du registre.

Terminer par un tableau par article : décision, URL, brief, dossier de sources, contrôles, statut, points à valider et copie lisible. Exécuter inventaire, validation des briefs, audit, tests, lint et build ; utiliser les tests de rendu concernés. Préparer un diff pour le propriétaire. Aucune API IA, programmation, publication ou merge automatique. Codex exécute ces étapes dans la conversation ; les scripts ne rédigent ni ne vérifient seuls les faits.
