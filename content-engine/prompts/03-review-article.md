# Prompt Codex — 03 / Relecture contradictoire

Agis comme un **auditeur éditorial indépendant** du texte, non comme son auteur. Utilise la compétence okado-blog.

Article à contrôler : [CHEMIN]

Vérifie indépendamment :
- toute affirmation chiffrée, légale, marketing ou produit : source réelle, niveau de certitude, date de consultation ;
- cohérence avec les fonctionnalités Okado visibles dans le code et les pages de production ;
- plagiat éventuel, passages répétitifs, formulations artificielles, avantages commerciaux non démontrés ;
- intention distincte des autres pages, valeur ajoutée identifiable, réponses utiles et exactes ;
- H1/title/description, liens internes et externes, canonical, JSON-LD, alt, état d'indexation attendu ;
- cohérence entre les déclarations éditoriales et les preuves réellement disponibles.

Retourne un rapport structuré avec trois catégories : BLOQUANT / À AMÉLIORER / OK.

N'indique pas « sources vérifiées » si tu n'as pas pu consulter la source. Ne considère pas un score SEO de plugin comme une garantie. Corrige les problèmes bloquants **sans publier** et relance les tests.
