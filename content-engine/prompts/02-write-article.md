# Prompt Codex — 02 / Rédaction et intégration

Utilise la compétence okado-blog. Sujet/brief : [COLLER LE CHEMIN DU BRIEF].

Tu dois produire un article **dans le format existant du blog**, sans créer un second moteur de rendu.

Ordre :
1. Lis le brief, l'inventaire des pages, la base de connaissances et les composants existants.
2. Vérifie sur des sources consultables les faits externes et les fonctionnalités d'Okado ; si la recherche externe est indisponible, conserve un brouillon bloqué, indique les sources nécessaires et n'invente rien.
3. Présente une réponse directe à la question, une structure utile et un angle original. Ajoute des exemples honnêtes : simulation/estimation avec hypothèses explicites si ce ne sont pas des données réelles.
4. Réutilise les composants d'article, les liens internes existants et le schéma SEO/JSON-LD du site. Prépare une suggestion d'image seulement si elle apporte une valeur ; n'insère pas de fausse photographie de client.
5. Écris la pièce dans le bon dossier, sans date future, sans auteur inventé et sans FAQ forcée.
6. Lance le lint, les tests, le build et les validations éditoriales réellement disponibles. Corrige les problèmes causés par tes changements.
7. Livrer : diff des fichiers, sources consultées, contrôles réussis/échoués, limites, points à valider.

Interdiction de publier, fusionner ou modifier les pages existantes hors du périmètre approuvé. Si le brief décide UPDATE, modifier la page existante plutôt que créer un doublon.
