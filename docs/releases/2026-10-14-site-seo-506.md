## Architecture

`src/lib/site.ts` définit URL, métadonnées et entités communes. `public-content.ts` fournit les contenus typés, rendus statiquement par `[...slug]/page.tsx` ; les URL inconnues restent en 404. La date de vérification est explicite, non régénérée artificiellement à chaque build. Les images publiques sont dérivées des assets versionnés du produit via `scripts/optimize-landing-assets.mjs`, sans utiliser des logos ou données clients. `next/image` conserve les dimensions et tailles adaptées. L'OG de marque est calculé à la compilation avec `ImageResponse`, sans requête externe à l'exécution.

Le graphique de démo reste côté client, mais sans Recharts. La simulation ne publie aucun avis, ne transmet pas les champs saisis et n'envoie aucun e-mail ; le minuteur est nettoyé au démontage et à la remise à zéro. Le prix localisé utilise un snapshot SSR stable pour éviter l'erreur d'hydratation. Pas de dépendance ajoutée au projet ni changement de forfait.

Contrôle du premier candidat Vercel : sources WebP et optimiseur 200, mais `/og-image.png` était absent malgré le succès local. Le motif global `*.png` exclut aussi les dossiers de ce nom : exceptions explicites ajoutées pour `src/app/og-image.png` et son contenu, en plus des images publiques. Cette vérification doit être répétée sur le nouveau commit et ne peut être remplacée par le build local.

## Poids mesurés, 14 octobre 2026

Protocole reproductible : `node scripts/measure-landing-payload.mjs http://localhost:3210` contre le build de production local, puis même script contre `https://www.okado.app` avant livraison. GET successifs avec `Accept-Encoding: gzip`, somme des JS/CSS référencés dans le HTML initial, polyfill nomodule compris. Ne mesure pas les imports à la demande, le cache du navigateur, les scripts tiers chargés ensuite, le CPU, LCP/INP/CLS ou un temps d'affichage. Les environnements CDN/local diffèrent ; la comparaison porte sur les octets, pas leur latence.

| Page | JS production avant (octets gzip) | JS candidat local (octets gzip) |
| --- | ---: | ---: |
| Accueil | 293 353 | 183 450 |
| Restaurants | 298 294 | 188 431 |
| Beauté | 293 353 | 188 431 |

CSS : 12 644 → 10 222 octets gzip. Photo source PNG : 1 921 542 octets ; WebP utilisé : 111 574 octets, 1600×900. Cinq échantillons décor : 17 042 à 30 332 octets chacun. Les chiffres du build final peuvent varier légèrement après toute modification. Le script échoue sur un HTTP non-200 : `/tarifs` et `/guides` n'existent pas dans l'ancienne production, ce qui explique son arrêt après les trois pages historiques lors de la comparaison.
